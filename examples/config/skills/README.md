# Skills

Skills (Agent Skills format) that agent profiles list in `spec.skills`. Each directory
with a `SKILL.md` is one skill; every file in it is copied into the agent's sandbox.

| Skill | Source | Version |
| --- | --- | --- |
| `tdd` | [mattpocock/skills](https://github.com/mattpocock/skills) `skills/engineering/tdd` | same copy as `.agents/skills/tdd` (hash in `skills-lock.json`) |

Skills are pinned by being copied here; update them through a pull request.
